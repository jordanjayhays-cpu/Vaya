# ops

Templates and the tracker. **Everything here has `[SQUARE BRACKETS]` where a real value goes. Do not send anything with a bracket still in it.**

| File | What it is | Fill in when |
|---|---|---|
| `revenue-tracker.csv` | One row per paid transaction. **The episode code column is the whole point** | From the first peso |
| `invoice-template.md` | What an invoice says | When the EIN lands |
| `videographer-engagement.md` | The copyright assignment. **Before the first shoot day** | Before November |
| `partner-agreement.md` | The email that makes a handshake a supply chain | With each of the four partners |
| `move-in-brief.md` | The intake call for a PHP 45,000 product | Before the first Move In |

## The one rule for the tracker

**Every row gets an episode code, or `none` if the customer did not come from a film.**

Revenue per film is the only success metric that counts, and **you cannot reconstruct this later.** A row without a code is a row that teaches you nothing.
