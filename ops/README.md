# ops

Templates and the tracker. **Everything here has `[SQUARE BRACKETS]` where a real value goes. Do not send anything with a bracket still in it.**

| File | What it is | Fill in when |
|---|---|---|
| `revenue-tracker.csv` | One row per paid transaction. **The episode code column is the whole point** | From the first peso |
| `invoice-template.md` | What an invoice says | When the EIN lands |
| `videographer-engagement.md` | The copyright assignment for the camera. **Before the first shoot day** | Before November |
| **`correspondent-engagement.md`** | **The copyright assignment for written and on-camera work, plus the contractor terms.** Higher risk than the videographer's | Before the first film or newsletter |
| `partner-agreement.md` | The email that makes a handshake a supply chain | With each of the four partners |

| **`day-one.md`** | **The first day with the correspondent and the videographer.** Half setup, half a real shoot | The day they start |
| **`newsroom.md`** | Who delivers what, the film cycle, the week, the correction process | Read once, then it runs itself |
| **`footage-pipeline.md`** | Naming, offload, backup, releases. **The only process here where a mistake is unrecoverable** | Before the first shoot |
| **`publish-checklist.md`** | The 32-line gate that makes `standards.html` true rather than decorative | Every film, every time |
| **`episode-brief-template.md`** | The one-pager that decides whether a film is worth a shoot day | Before any shoot date |
| **`episode-tracker.csv`** | Views, emails, bookings and revenue, per episode code | From the first published film |

## The one rule for the two hires

**They are independent contractors, not employees.** Everything in `newsroom.md` and `day-one.md` is written as deliverables to a standard by a date, never as hours or task assignment. **If a process here starts reading like management, it is written wrong**, and it becomes evidence of employment with back pay attached. Lawyer question 5 in `outreach/08` settles the detail.

## The one rule for the tracker

**Every row gets an episode code, or `none` if the customer did not come from a film.**

Revenue per film is the only success metric that counts, and **you cannot reconstruct this later.** A row without a code is a row that teaches you nothing.
