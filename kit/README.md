# Vaya production kit

The graphics package for every Vaya film. The rules are in the published "Vaya Production Kit" page and in `BRAND.md`. Editors import these SVGs, install the two fonts, and follow the rules.

| File | What it is | Where it goes |
|---|---|---|
| `01-open-title-card.svg` | The open: series label, the question, the number pill, wordmark | Seconds 3 to 10 of every episode |
| `02-lower-third.svg` | Name, role, neighborhood, hibiscus bar | First time each person speaks, 4 seconds |
| `03-price-tag.svg` | White card, hibiscus stroke, label and number | The moment a number is said, 3 seconds |
| `04-receipt-end-card.svg` | The receipt on ink, the Vaya line last in red, the episode code | The last 15 seconds |
| `05-thumbnail.svg` | 1280 by 720: number left, real person right, neighborhood pill, wordmark | YouTube thumbnail, two variants tested per film |

**The pace rule.** Every three seconds something changes: a cut, an angle, a graphic in or out, a punch-in, b-roll, a price tag, a receipt row. Never the same frame for more than three seconds. Shoot every interview on two angles and 60 seconds of b-roll per minute of screen time. Before export, scrub at 3-second marks and fix any gap.

Fonts: Plus Jakarta Sans (800 for headlines, 600 for captions) and DM Mono (labels, numbers). Both free on Google Fonts. Install them before opening the SVGs or the text falls back.

Colors: hibiscus #FF2D55, tangerine #FF8A3D, ink #23141B, paper #FFFFFF. The brand colors live in the graphics, never in the footage grade.

Episode codes: EP01, EP02, and so on. The code is on the receipt, in the description link (`vayanews.com/manila?ep=01`), and in the email subject when someone books. Revenue per film is counted by code.
