# Shooting briefs

One per launch film. **Send to the videographer and the correspondent before the shoot week, along with `kit/README.md` and `BRAND.md`.**

| Brief | Code | Sells | Page the end-card names |
|---|---|---|---|
| `01-block-by-block.md` | **EP01** | **Nothing.** The flagship. It builds the audience the others convert | `vayanews.com/starter-kit`, the free guide |
| `02-visa-truth.md` | **EP02** | Vaya Desk — Visa | `vayanews.com/visa` |
| `03-naia.md` | **EP03** | Vaya Concierge — Landing | `vayanews.com/landing` |
| `04-eat-here.md` | **EP04** | Vaya Tours — Food | `vayanews.com/food-tour` |
| **MISSING** | **EP05** | **Vaya Home — Move In** | `vayanews.com/move-in`, **live and selling at PHP 45,000 with no brief written** |

**The numbering is one system, fixed 2026-10-10.** Brief file number = episode code = the number on the receipt end-card = the number on the homepage card = the number in the email subject line. `kit/README.md` is the source of truth and it says EP01 onward. **Before 10 October the pages were running one ahead of the briefs**, so a viewer would have seen EP03 on a film and EP02 on the homepage for the same thing. Nothing external referenced the old codes, because no film is published, which is why this was free to fix.

**Why the code matters:** it is the only attribution Vaya has. One film points at one page, and that page's email button carries the code in the subject line. **That subject line is how you know which film earned the money.** See `FUNNEL.md`.

## Rules that apply to all five

- **Something changes every three seconds.** New angle, new graphic, new sound, new face. Per `BRAND.md`.
- **Every price on screen carries the date it was checked.**
- **No health, medical or therapeutic claims.** Ever. Cut them in the edit even if someone said them. See `research/company-films-legal.md`.
- **Nobody appears without a signed release.** Blanks in the bag, every day.
- **The disclosure line is spoken in the same breath as any recommendation.** On a route and we earn, no relationship, or they comped it.
- **The service is one line at the end.** Under 15 seconds. The film is about the problem, not the product.
- **The end-card URL is spoken and shown, and it is the extensionless one.** `vayanews.com/visa`, not `vayanews.com/visa.html`. Both work, the short one is the one people can retype from memory. **Verified resolving on 10 October 2026.**
- **Licensed music only.** Receipt filed with the project.
